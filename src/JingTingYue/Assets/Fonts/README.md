# Bundled Chinese fonts

| Font | Use | Source | License |
| --- | --- | --- | --- |
| Noto Serif SC (variable) | Default reading text and share card quotation | https://github.com/google/fonts/tree/main/ofl/notoserifsc | SIL Open Font License 1.1; see `NotoSerifSC/OFL.txt` |
| LXGW WenKai Regular | Optional reading text and share card note | https://github.com/lxgw/LxgwWenKai | SIL Open Font License 1.1; see `LXGWWenKai/OFL.txt` |

The original font files are bundled without modification. The complete typefaces are retained so imported EPUB books can display uncommon Chinese characters.
